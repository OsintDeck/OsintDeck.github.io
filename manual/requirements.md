# Requisitos técnicos

- **WordPress:** 5.8 o superior (según cabecera del plugin).
- **PHP:** 7.4 o superior.
- **Composer:** en desarrollo o si no usás el ZIP de Releases, ejecutá `composer install` en la carpeta del plugin para generar `vendor/`.

!> En producción es más simple instalar el paquete ZIP de **Releases**, que ya incluye `vendor/`.
